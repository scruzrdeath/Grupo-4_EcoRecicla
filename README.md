# ♻️ EcoRecicla

## 📖 Descripción y objetivo

EcoRecicla es una aplicación que permite consultar puntos de reciclaje, aprender a separar residuos, registrar el reciclaje realizado y visualizar el progreso personal, promoviendo hábitos sostenibles.

**Objetivo:** diseñar una solución digital que facilite la consulta de puntos de reciclaje, el aprendizaje sobre la separación de residuos y el registro de acciones ecológicas.

## 🎯 Problema que busca resolver

La comunidad necesita información accesible para separar residuos correctamente, ubicar puntos de reciclaje y conocer el impacto de sus acciones.

## 🚀 Instrucciones iniciales para ejecutar o revisar el proyecto

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/<usuario>/EcoRecicla.git
   cd EcoRecicla
   ```

2. Revisar la documentación en `docs/descripcion_proyecto.md`.
3. Ejecutar el código inicial (requiere Python 3.8 o superior):

   ```bash
   python src/main.py
   ```

4. Consultar el historial de commits:

   ```bash
   git log --oneline
   ```
