# Descripción del proyecto — EcoRecicla

## Proyecto
EcoRecicla es una aplicación para apoyar y motivar el reciclaje. Permite consultar puntos de reciclaje, aprender a separar residuos, registrar el reciclaje realizado y visualizar el progreso personal.

## Objetivo
Diseñar una solución digital que facilite la consulta de puntos de reciclaje, el aprendizaje sobre la separación de residuos y el registro de acciones ecológicas, promoviendo hábitos sostenibles.

## Necesidad identificada
La comunidad necesita información accesible para separar residuos correctamente, ubicar puntos de reciclaje y conocer el impacto de sus acciones.
